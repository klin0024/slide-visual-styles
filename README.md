# 投影片視覺風格

一套現成的簡報視覺風格提示詞(prompt)收藏庫。每個 `.md` 檔案都是一份完整的「設計定義」提示詞,涵蓋色彩配置、字體排印、版面規則與整體視覺風格,可直接複製貼上到 NotebookLM 等簡報生成工具,快速產出風格統一、視覺質感高的投影片,不需要自己從零設計版面。

風格依主題分為六大分類(商業媒體與雜誌風、極簡與專業風、插畫與角色風、復古科技與像素風、藝術與普普風、產品與科技展示風),可依簡報的使用情境與受眾挑選最合適的風格。

## 使用方式

1. 依需求情境挑選對應分類與風格
2. 開啟該風格的 `.md` 檔案,複製「提示詞」完整內容
3. 貼到 NotebookLM 簡報生成的說明欄位使用
4. 想先看成品效果,可參考下方的 [NotebookLM 簡報](#notebooklm-簡報)與 [HTML 動態簡報](#html-動態簡報)範例
